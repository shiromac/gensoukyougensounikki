# Archived manual

This directory contains a local archive of the original online manual for
`幻想郷幻想日記`.

Original URL:

- http://atn-factory.jp/ggn/manual/

Archived on: 2026-06-14

Open `index.html` to read the manual locally. The HTML, images, and screenshots
are included as game documentation for this repository and release packages.
They must not be extracted, redistributed, or reused as standalone material
assets.
