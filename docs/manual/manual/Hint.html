初心者向けTIPS

敵とは１対１で戦え！

複数の敵と戦うのは非常に不利です。
通路などの狭い場所に逃げ込んで、なるべく１対１で戦いましょう。

じっくり考えて動け！

自分が行動するまで敵は行動しません。
ピンチになっても冷静にじっくり次の一手を考えましょう。

ボス弾幕をよけろ！

ボス弾幕はじっくり観察すれば次にどの方向に動くのかわかります。
弾幕の動きを見切れば弾幕を避けるのはそこまで難しくないはずです。
どうしても避けられないなら倒してしまいましょう。

ゲームのヒント
  • 既存の某有名ローグライクをプレイしている方は、次のように読み替えれば分かりやすいと思います。
    • コッペパン = おにぎり or パン
    • 飲み物 = 草 + 札
    • スペルカード = 巻物 + 腕輪
    • 本 = 杖
    • にとり = ペリカン or マ○ルン
    • 壺でも異種合成ができる
    • 宴会 = モン○ウ
  • 飲み物で付与できる御霊の強さは、飲み物自身の修正値に左右されます。
  • カクテル合成は、材料さえあれば狙った飲み物が確実に手に入るので非常に強力です。
    混酒の箱を見つけたら積極的に使ってみましょう。
  • スコアは経験値、ターン数、持込道具などで決まります。

困ったことがあったら

 よくあると思われる質問事項を以下に挙げますので、まずはこちらをお読み下さい。
お読みになった上で、それでも解決できない場合は、弊サークルサイトのサポートBBSまでお願いいたします。

d3dx9_○○.dllが見つかりません。と表示され起動できない

お使いのPCのDirectXのバージョンが古いと思われます。
インターネット上で入手し、インストールをお願いします。

画面がおかしい。うまく描画されない

ビデオカードのドライバが古い可能性があります。
お手数ですが、ドライバのアップデートをお試しください。

ゲームのプレイ経過がセーブできない

  • ゲームのインストール作業は行いましたか？→はじめかた
  • 再開時のスタート位置は常に詰め所です。
    また、ダンジョンの中断が可能なのは「フロア開始時」のみです。
    →ゲームを中断するには
  • 「C:\Program Files」内にデータを展開、もしくは保存しようとしていませんか？
    この場合は、ゲームの展開位置や保存する場所を、「C:\Program Files」内以外の場所に変更すると解決することがあります。
  • 管理者権限でゲームを起動するようにすると解決することがあります。

これは仕様ですか？

以下の挙動は仕様となっております。
  • コマンド「拾う」にターンを消費しない。
  • 敵攻撃時に敵の足元に罠があった場合、罠が露見する。
  • 味方キャラと場所を入れ替えたとき、移動先の効果(道具の拾得・罠の発動・階段の選択肢)が発揮されない。
    ※足元コマンドをお使いください。
  • 宴会に遭遇しても、ミニマップ上の敵位置表示が全域にならない。
  • 詰め所に戻っても装備が外れない。
  • 箱を倉庫に入れる際、箱に入っている道具も倉庫の容量を消費する。
  • 混酒の箱で作った飲み物に信仰・呪いが付与されていることがある。
  • 濃縮合成の際の修正値増加が思ったより多い。
    ※少し計算方法が特殊です。→道具の合成
  • 店内の弾幕を撃って、弾が床に落ちたとき、
    • 撃った分の費用を請求される。
    • 撃って床に落ちた弾に値札がつかない。
  • 店主を倒して店外に出ても泥棒扱いになる。
  • 泥棒した後に店に行くと、貸しが0になっている。

キーコンフィグで、キーボードのコンフィグができない

申し訳ありませんが、キーボードは、キーコンフィグに対応しておりません。
何卒ご了承ください。

プレイ動画やスクリーンショットを撮って公開してもいいですか？

基本的には、当サークルのサイトの記述に準じます。
ただし本ゲームは特例として、一部のデータを差し替えることを許可しております。
詳細は同梱の「graphic/interfaceについて.txt」、「data/Languageについて.txt」を御覧ください。

メニュー画面が重い

タイトル画面のコンフィグで「文字描画の精細さ」を下げると、描画が高速になります。
一度お試しください。
